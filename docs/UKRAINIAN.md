# Українська версія: карта, телефони, гра через інтернет

Ця гілка форку додає до D&D-скіла:

- **Живу карту підземелля** — на екрані ведучого (кнопка 🗺 «Карта») і на телефоні кожного гравця (вкладка «Карта»): кам'яна підлога, стіни, ґрати й двері, жаровні, що освітлюють темряву, фішки героїв (смолоскип світить навколо), позначки, сірі хрестики там, де загинули вороги, і плями з грошима після смерті героя. Недосліджене не малюється. Ведучий оновлює її командою `display/map.py` після кожної дії; карта зберігається з кампанією (`map.json`).
- **Українську мову інтерфейсу** — кнопки, вкладки, кубики, аркуш, статуси. Вмикається для кампанії рядком `ui_language: uk` у `state.md → ## Session Flags` (або `?lang=uk` в адресі на конкретному пристрої). Рядок `language: uk` змушує ведучого вести всю гру українською.
- **Тему «Попіл»** (Ash) у дусі Dark Souls: холодний камінь, кістяно-білий текст, жаровий акцент. За замовчуванням для кампанії — `display_skin: ash`; кожен пристрій може змінити в Налаштуваннях → Стиль.
- **Гру через інтернет** — `start-display.sh --tunnel` відкриває екран через безкоштовний тунель Cloudflare і друкує **посилання-запрошення**. Друзі відкривають його з телефона вдома.

На телефоні тепер чотири вкладки: **Хід · Кидок · Аркуш · Карта**. «Кидок» — це і вільний кидок будь-яких кубиків (d4–d100, бонус, перевага/перешкода), і кидок, який просить ведучий (він з'являється сам, з уже виставленим бонусом).

## Встановлення (Windows, один раз)

1. **Python-залежності екрана:**
   ```
   pip install -r skills/dnd/display/requirements.txt
   ```
2. **Cloudflare tunnel** — лише для гри через інтернет:
   ```
   winget install --id Cloudflare.cloudflared
   ```
   Після встановлення перезапусти термінал / Claude Code.
3. **Скіл із цього форку** — встанови або онови його в Claude Code з репозиторію `dpan9294/claude-dnd-skill`, гілка `ukrainian-map-table` (або `main` після злиття). Найпростіше попросити про це сам Claude Code: *«Встанови D&D-скіл з github.com/dpan9294/claude-dnd-skill, гілка ukrainian-map-table, замість поточного»*.

## Як грати з друзями через інтернет

1. У Claude Code: `/dm:dnd load <кампанія>` → на питання про екран обери **Display (internet)**.
2. Claude надрукує посилання на кшталт `https://xxxx.trycloudflare.com/join?key=…` — надішли його друзям особисто (не в публічний чат).
3. Друг відкриває посилання з телефона → обирає свого героя → бачить вкладки Хід / Кидок / Аркуш / Карта.
4. Екран ведучого відкривається на твоєму комп'ютері (`http://localhost:5001`) — його можна показати через демонстрацію екрана в Discord.

**Безпека:** через тунель доступні лише дії гравців (надіслати хід, кинути кубик, подивитися аркуш і карту). Розповідь, статистику, карту і запити кидків змінює тільки ведучий на твоєму комп'ютері. Посилання перестає працювати, щойно екран зупинено; при кожному запуску ключ новий.

## Шпаргалка для ведучого (map.py)

```
python3 display/map.py hero "Діма" 12 18 --light 4     # пересунути героя (смолоскип)
python3 display/map.py room mess 10 18 10 7 --name "Їдальня"
python3 display/map.py door 20 22 v --kind wood --state locked
python3 display/map.py brazier b3 14 18 --name "камін" --lit
python3 display/map.py dead 12 18 "Згаслий"
python3 display/map.py stain "Ілля" 12 18 "20 зм"       # смерть: гроші лишились тут
python3 display/map.py where "БІЙ · Раунд 2: ▶ Ілля → Діма → Згаслий"
python3 display/map.py log "Ілля відімкнув їдальню."
```

Повний список — `python3 display/map.py --help` або `skills/dnd/SKILL-scripts.md → Map Script`.
